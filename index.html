What is This?

A zero-trust deployment configuration router. Define your environment variables per platform, validate them against platform-specific contracts, and export deployment-ready config files — all from your browser. No secrets are ever stored or transmitted.

Profiles are saved in localStorage. Contract validation runs entirely client-side. Export formats generate references to your secret manager, never actual values.

Quick Start

  1. Browse Platforms to see supported deployment targets.
  2. Create a Profile — choose a platform, add env vars with secret refs.
  3. Validate your profile against the platform contract.
  4. Export deployment-ready config (env-file, k8s YAML, GitHub Actions, etc.).
  5. Missing a platform? Submit a new contract via GitHub PR.
